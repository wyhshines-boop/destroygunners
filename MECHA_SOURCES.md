# Mecha catalog

`src/data/mecha.json` contains the 23 original playable DGZZ mechs, ordered by the game's body table. Names and order are from `tools/dgzz_unlock_research/robots.json` (original first23 entries); descriptions are game text IDs263–285 from `tools/dgzz_tutorial125/strings.json`, with Chinese from the corresponding `full_translations.json` in the GREE workspace. Game line-break/color codes are removed for web display.

For DFA-0C (text276), the original English says `DFA-9/Bst`; Japanese identifies `DFA-0/Bst`. English and Chinese use the Japanese model reference. Descriptions convey the game's model lore, not independent balancing claims or unlock instructions.

Images are optional and currently null. To add a screenshot, put the compressed image in public/community/mecha/ and set the matching record's image to its /community/mecha/...webp path. No generic, AI-generated, or incorrectly matched model images are substituted. Cards render text immediately and include images only when assigned. This revision does not change the game APK, download links, or editorial commentary.
